# Changelog

## 0.1.2 - 2026-10-30

### Changed

- Require `@vited/core` 0.2 or newer as a peer dependency.

## 0.1.0 - 2026-10-27

Initial release.

### Added

- `vited dev`, `vited build`, and `vited preview` commands backed by Vite.
- Support for a project root, custom Vited config file, and host/port options for development and preview.
- `@vited/core` and Vite peer dependencies.
